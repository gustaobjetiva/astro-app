# ASTRO — app do Grupo Objetiva (Android)

Aqui ficam **apenas os instaladores** do aplicativo. O código-fonte é
privado; este repositório existe para que o próprio app consiga ver que
saiu versão nova e se atualizar sozinho, sem precisar carregar nenhuma
senha por dentro.

## Instalar

1. Abra a página de [**releases**](../../releases/latest) **pelo celular**
2. Baixe o arquivo `.apk`
3. Toque no arquivo baixado

Na primeira vez o Android pergunta se pode instalar aplicativo de fora da
Play Store — permita para o navegador que fez o download. Das próximas
vezes o próprio app avisa quando houver versão nova.

## Acesso

Baixar o aplicativo não dá acesso a nada. Ao abrir, ele pede login, e cada
e-mail precisa ser **aprovado** por um responsável do Grupo Objetiva antes
de enxergar qualquer informação.

Quem ainda não tem conta usa **Primeiro acesso → Solicitar acesso** dentro
do próprio app e aguarda a liberação.
